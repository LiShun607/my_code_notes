# 23 ADC多通道 + DMA 数据自动转运

解决项目21中CPU频繁等待ADC转换的问题。利用DMA，让ADC转换完的数据自动存进数组。
- 核心配置：ADC开启扫描模式和多通道。DMA配置为 `DMA_Mode_Normal`（非循环模式），在主循环中调用一次转换函数就转换一轮，（当然也可以用ADC的连续转换搭配DMA的循环模式），外设地址填 `&ADC1->DR`，内存地址填自定义的 `ADValue` 数组。
- 数据流向：ADC每转换完一个通道，就会触发一次DMA请求，DMA自动把 `ADC->DR` 寄存器里的值搬进数组，然后自动指向数组的下一个元素。
- 优点：CPU彻底解放，只需要在主循环里随时去数组里拿最新数据就行了，非常丝滑。
