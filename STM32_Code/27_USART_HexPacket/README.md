# 27 USART 收发 HEX 数据包（状态机首秀）

这是我第一次在单片机里写出“状态机”。之前发单个字节很容易受到干扰，这次通过“包头+数据+包尾”的格式，保证了数据传输的可靠性。
- **发送端**：按键按下，4字节的 `TxPacket` 数组自增。调用 `Serial_SendHexPacket`，按照 `[0xFF] + [4字节数据] + [0xFE]` 发送出去。
- **接收端（核心）**：在中断里引入了 `RxState` 状态机。
  - 状态0：等待包头 `0xFF`。
  - 状态1：接收4个有效数据存入数组。
  - 状态2：验证包尾 `0xFE`。
- **踩坑记录（防死锁）**：一开始如果包尾不对，状态机卡在状态2不动了，导致后续再也收不到数据。后来加上了 `else { RxState = 0; }` 的容错处理，一旦遇到错误数据包直接丢弃重来，鲁棒性大幅提升。
