# 18 定时器输入捕获测频率及占空比

这是定时器章节最高级、也是最难的项目，学会了用硬件去“测量”外部信号。
- 硬件连接：**必须用一根杜邦线把 PA0（PWM输出）和 PA6（TIM3_CH1输入）短接**，自己测自己发出的信号。
- 核心配置：使用了 `TIM_PWMIConfig` 自动配置通道1和通道2（一个测周期，一个测高电平时间）。配置了主从模式（Reset），每次捕获到上升沿自动把计数器清零，方便计算。
- 计算逻辑：
  1. 频率 = 1000000 / CCR1（因为定时器是1MHz计数）。
  2. 占空比 = (CCR2 * 100) / CCR1。
- 踩坑记录：
  1. 算占空比时，因为是整数除法，直接用 `CCR2 / CCR1` 永远等于 0，必须 **先乘以 100 再除**。
