# 12 按键控制流水灯重构（定时器中断版）

这是我独立完成的最有成就感的一次重构，彻底消灭了之前的卡顿问题。
- 以前的问题：因为主循环里用了 `Delay_ms` 死等，按键必须长按才能识别，流水灯卡顿。
- 重构思路：把主循环和定时器中断分工。主循环只负责读按键、翻转状态变量 `RunMode`；定时器中断（100ms一次）里执行流水灯的移动。
- 踩过的坑：
  1. 一开始想在中断里写 `for` 循环让灯全部亮一遍，发现不对。后来写了一个 `LED_Step()` 函数，每次中断只让灯移动一格，并用变量记录方向和 `Last` 位置，实现了双向无缝流水。
- 最终现象：无论流水灯跑得多快，按下按键瞬间就能停或者启动，按键再也不卡顿，丝滑顺畅。
