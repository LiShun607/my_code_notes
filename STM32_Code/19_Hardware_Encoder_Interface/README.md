# 19 定时器编码器接口测速（硬件解码）

之前用外部中断写旋转编码器（项目10），代码长且占用CPU。这次用STM32自带的硬件定时器“编码器接口”模式，代码量直接减半，且自带硬件滤波。

- **硬件与GPIO配置**：使用 TIM3 的通道 1 和 2（PA6、PA7），配置为上拉输入。使用 `TIM_EncoderInterfaceConfig` 将 TIM3 设置为编码器模式（TI12），这样无论是正转还是反转，硬件底层会自动控制 CNT 寄存器加减，完全不需要写中断。
- **核心测速逻辑**：
  1. 配置 TIM2 定时 1 秒（PSC=7200-1, ARR=10000-1）产生中断。
  2. 在 TIM2 的中断服务函数里，执行 `TIM_SetCounter(TIM3, 0)`，把 TIM3 的计数值清零。
  3. 主循环里直接读 `TIM_GetCounter(TIM3)`，这个读到的值，就是过去 1 秒内编码器转过的脉冲数，也就是**速度**。
- **踩坑记录（数据类型转换）**：
  当编码器反转时，TIM3 的硬件 CNT 会从 0 开始往下减，底层寄存器里其实是从 65535 开始倒数。
  如果直接返回无符号整数，反转的速度会变成 65535 这种极其巨大的数字。
  所以在 `Encoder_Speed()` 函数里，必须把 CNT 强转为 **`int16_t`** 类型，这样底层就会按补码处理，65535 就会变成 -1，完美还原负数速度。
- **心得**：这让我体会到了什么是“硬件外设”。能用硬件底层自动完成的事，绝对不用软件写中断去死磕，这就是STM32的强大之处。
