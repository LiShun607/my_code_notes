# 16 PWM驱动直流电机（按键调速）

这是直流电机控制的基础项目，实现了按键调节速度和正反转。
- 硬件逻辑：电机除了需要PWM调速信号，还需要两个普通GPIO（PA4, PA5）接入电机驱动模块（TB6612）来控制正反转。一高一低正转，一低一高反转。
- 高频PWM：为了让电机运转时听不到人耳能察觉的“啸叫声”，我把PWM频率设置成了 20kHz（PSC=36-1, ARR=100-1）。
- 速度映射：在 Motor_Speed 函数里，传入正数则正转，传入负数则反转（代码里取了绝对值给PWM）。
- 测试功能：按键按下，速度每次增加20，超过100自动变成-100开始反转，屏幕上显示当前的速度值。
