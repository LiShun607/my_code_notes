# 29 综合实战：传感器数据实时监控系统

这是本周的终极压轴项目，把定时器、ADC和串口通信全部串联在了一起。
- **硬件自动触发**：利用 TIM3 定时器每 1 秒产生 TRGO 信号，硬件直接触发 ADC 转换，完全不占用 CPU。
- **中断规范**：ADC转换完成后，在 ADC 中断里只做一件事：`AD_Flag = 1;` 并清除中断标志位。
- **主循环调度**：在 `while(1)` 中判断 `AD_Flag`，读取数据、刷新 OLED，并用之前封装好的 `Serial_Printf` 打印到电脑串口助手。
- **踩坑反思**：
  1. 最开始把 `Serial_Printf` 直接写在了 ADC 的中断服务函数里，导致系统频繁卡死。深刻理解了“中断里绝对不能做耗时操作”的铁律。
  2. 测试时拧动电位器/遮挡光敏传感器，看着串口助手里数据从几百跳到四千多，真真切切感受到了模拟量与数字量转换的魅力。
