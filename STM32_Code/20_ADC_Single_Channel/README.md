# 20 ADC单通道采集与电压转换

这是我学习模拟量采集的第一个项目，实现了将电位器的模拟电压转化为数字量并在OLED显示。
- 硬件连接：电位器中间引脚接 PA0，两端分别接 3.3V 和 GND。
- 核心配置：开启ADC1时钟，配置 PA0 为模拟输入（AIN），配置 ADC 为单次转换、软件触发、右对齐模式。执行了 ADC 校准代码。
- 数据换算：STM32的ADC是12位的，读出来的原始值范围是 0~4095。通过公式 `(float)ADValue / 4095 * 3.3` 将其线性映射为 0~3.3V 的实际电压。
- 踩坑记录：OLED 库没有直接显示浮点数小数的函数。为了实现 `Vol: 1.23V` 的效果，我利用 `(uint16_t)(Voltage * 100) % 100` 把小数部分强行截取出来单独显示，巧妙的解决了这个问题。
