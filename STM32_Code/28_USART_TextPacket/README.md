# 28 USART 收发文本数据包（字符串解析）

这个项目实现了接收“字符串”指令。比如你在电脑上敲 `LED_ON`，单片机能识别并开灯。
- **协议设计**：定义了 `@` 作为包头，`\r\n`（回车换行）作为包尾。
- **接收状态机**：和上一个项目类似，但这次存入的是字符数组 `RxTextPacket`。避坑点：在验证完 `\r\n` 后，千万记得手动在数组末尾加上 `'\0'`，否则在后续处理字符串时会发生越界乱码。
- **指令匹配**：在 `main.c` 中，使用 `strcmp` 函数将接收到的字符串与 `"LED_ON"` 和 `"LED_OFF"` 进行比对，从而控制硬件。如果输入了不认识的指令，单片机会给电脑回复 `ERROR COMMEND!`。
- **心得**：这其实就是智能家居物联网控制的底层逻辑原型（通过串口/WiFi发文本指令控制硬件）。
