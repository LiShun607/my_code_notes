# 22 DMA数据转运（内存到内存）

这是DMA（直接内存访问）的入门项目，实现了让硬件自动把数组A的数据搬运到数组B。
- 核心配置：配置 DMA1_Channel1，方向选择 `DMA_DIR_PeripheralSRC`（外设作源，即内存A），开启 `DMA_M2M_Enable`（内存到内存软件触发）。
- 踩坑记录：DMA在更改转运次数之前，**必须处于失能状态**（`DMA_Cmd(... DISABLE)`），否则配置会失效。
- 现象验证：在 main 函数里，先显示数组A，调用一次 `MyDMA_Transfer()`，再显示数组B。肉眼直观地看到数据被成功复制，且整个过程CPU只是下达了一次指令，搬运全交给了硬件。
