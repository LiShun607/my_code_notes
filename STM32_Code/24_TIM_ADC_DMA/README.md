# 24 TIM + ADC + DMA 硬件自动触发（完全独立查阅资料完成）

这是本周最硬核的项目，也是我第一次完全脱离视频，自己查《参考手册》写出来的代码，极具成就感！
- 痛点解决：前几个项目中，ADC要么靠软件手动触发，要么靠CPU死等。在实际工业控制中，我们需要按照固定的频率（比如每1ms）精准采样。
- 核心架构：彻底抛弃CPU干预！
  1. 配置 TIM3 定时器，设置它的 TRGO (Trigger Output) 信号为 Update 事件（即定时器溢出时发出信号）。
  2. 配置 ADC 的外部触发源为 `ADC_ExternalTrigConv_T3_TRGO`。
  3. 开启 ADC 的 DMA 请求，且 DMA 配置为循环模式。
- 运行流程：定时器时间一到 -> 硬件自动通知ADC开始转换 -> ADC转换完 -> 硬件自动通知DMA把数据搬进数组。**全程CPU都在 `while(1)` 里睡大觉，看一眼寄存器，数据就已经完美按周期排好在了内存里。**
- 心得：这就是 STM32 强大的地方，理解了底层硬件触发链路，代码不仅优雅，而且实时性极高。第一次实现了硬件的自动化，终于和我的专业形成了一点闭环。
