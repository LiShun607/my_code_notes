# 17 旋转编码器控制直流电机

这是“输入（编码器） -> 处理 -> 输出（PWM电机）”的完整闭环雏形。
- 核心功能：拧动旋转编码器，电机转速跟着变化；反向拧，电机反转。
- 踩坑记录（边界横跳问题）：一开始在 `while(1)` 里用两个 `if` 分别判断编码器值 `>100` 和 `<-100`，结果在正向超过100时，屏幕数值和电机状态在 100 和真实数据之间疯狂横跳。
- 解决思路：因为第二个独立的 `if` 不成立时，程序会执行底下的 `else` 块，导致状态被反复覆盖。后来把第二个 `if` 改成了 `else if`，让这三个分支互斥，彻底解决了闪烁和逻辑冲突问题。
