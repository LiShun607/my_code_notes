# 15 PWM驱动舵机控制

实现了用按键控制舵机转动角度。
- 时基配置：PSC=72-1，ARR=20000-1。频率算下来是 50Hz（周期20ms），这是标准舵机的工作频率。
- 角度换算：舵机的控制脉宽是 0.5ms（0度）到 2.5ms（180度）。代码里封装了公式 `(Angle / 180 * 2000 + 500)`，把角度线性映射成了定时器的 CCR（比较寄存器）值。
- 功能实现：定义了一个全局角度变量，每按一次按键，角度增加30度，超过180度就回到0度，并在OLED上实时显示当前角度。
- 踩坑记录：一开始接上没反应，以为是代码错了。后来排查发现，STM32核心板的3.3V带不动舵机，必须把舵机的VCC接到面包板的5V外部供电上，并且必须和STM32共地，才能正常转动。
