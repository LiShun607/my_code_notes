# 11 定时器中断：TIM2 定时1秒

这是学完定时器章节后独立写的代码，重点在于搞懂定时时间是怎么算出来的。
- 时钟选择：TIM2 挂载在 APB1 总线上，时钟为 72MHz。
- 参数配置：为了得到 1 秒的定时，运用公式 `定时时间 = (PSC+1)*(ARR+1)/时钟频率`。
- 实际设置：`PSC = 7200-1`，`ARR = 10000-1`，计算出 `(7200 * 10000) / 72000000 = 1秒`。
- 中断逻辑：在 `TIM2_IRQHandler` 里让全局变量 `Timer_Count++`，并且一定记得清除中断标志位。
- 现象：OLED屏幕第一行显示中断次数，第二行显示硬件计数器的实时值，可以直观看到软件计数和硬件计数的区别。
