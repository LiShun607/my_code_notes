# 26 USART串口接收（中断法）

实现了单片机接收电脑发送过来的单个字节，并显示在OLED上。
- **硬件配置**：PA10(RX) 配置为上拉输入，开启了 `USART_IT_RXNE`（接收寄存器非空）中断。
- **中断逻辑**：在 `USART1_IRQHandler` 里，把收到的数据存到 `RxData`，并置位 `Serial_RxFlag`。严格按照“中断快进快出”的原则，没有在中断里写任何 Delay 或发送代码。
- **主循环处理**：`while(1)` 里轮询标志位，一旦标志位为1，就把数据用十六进制显示在OLED上，并原样发回给电脑（实现了串口回环测试）。
- **心得**：理解了串口接收的本质，其实就是硬件一收到电信号，立刻打断CPU存数据。
